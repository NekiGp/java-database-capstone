# Smart Clinic Management System - User Stories

## Admin

**Title:** Register Doctor

**User Story:**
As an Admin, I want to register new doctors so that they can provide medical services in the clinic.

**Acceptance Criteria:**
1. The admin can create a new doctor account.
2. The doctor's information is validated before saving.
3. The doctor is stored successfully in the database.

**Priority:** High

**Story Points:** 5

---

## Doctor

**Title:** View Patient Appointments

**User Story:**
As a Doctor, I want to view all my scheduled appointments so that I can manage my daily consultations.

**Acceptance Criteria:**
1. The doctor can retrieve appointments for a selected date.
2. Only appointments assigned to the logged-in doctor are displayed.
3. Appointment details include patient information and appointment time.

**Priority:** High

**Story Points:** 5

---

## Patient

**Title:** Book Appointment

**User Story:**
As a Patient, I want to book an appointment with a doctor so that I can receive medical care.

**Acceptance Criteria:**
1. The patient can search for doctors.
2. The patient can select an available appointment time.
3. The appointment is successfully saved in the system.

**Priority:** High

**Story Points:** 5
